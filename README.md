# Telegram SEO Audit Bot — версия на Node.js + Render

Бот с кнопками, диалоговым режимом (ссылка → ключевые слова, можно пропустить → результат → «Сравнить с конкурентом») и жирным форматированием в отчётах. Работает через вебхук — без «засыпания» и без проблем с редиректами, которые есть у Google Apps Script.

## 1. Запуск локально (для теста, необязательно)

Нужен установленный [Node.js](https://nodejs.org) (18+).

```bash
cd telegram-seo-bot
npm install
copy .env.example .env
```
(на Mac/Linux: `cp .env.example .env`)

Открыть `.env`, вставить токен от @BotFather вместо `paste_your_token_from_botfather_here`.

```bash
npm start
```

Должно появиться `SEO audit bot is running (polling mode).` — можно сразу тестировать в Telegram.

## 2. Постоянный хостинг на Render (бесплатно)

1. Зарегистрироваться на [render.com](https://render.com) через GitHub (без карты)
2. Загрузить папку `telegram-seo-bot` в свой репозиторий на GitHub (можно просто перетащить файлы через github.com → Create repository → Add file → Upload files)
3. В Render: **New → Web Service** → подключить этот репозиторий
4. **Build Command:** `npm install`
5. **Start Command:** `npm start`
6. В разделе **Environment** добавить переменную `BOT_TOKEN` со своим токеном
7. **Create Web Service** — Render соберёт и запустит бота, автоматически даст свой домен вида `https://ваш-бот.onrender.com`

Бот сам поймёт, что работает на Render (по переменной `RENDER_EXTERNAL_URL`, которую Render выставляет автоматически), и переключится в режим вебхука — ничего дополнительно настраивать не нужно.

## Как это ведёт себя

- **Бесплатно, навсегда**, в рамках лимитов Render (750 часов работы в месяц — с запасом для личного бота)
- Свободный сервис Render «засыпает» после 15 минут без обращений — первое сообщение после паузы может обрабатываться на 30-60 секунд дольше, пока сервис «просыпается». Все следующие сообщения — уже мгновенно
- Никаких скрытых редиректов (в отличие от Apps Script) — вебхук работает надёжно

## Обновление кода в будущем

1. Изменить файлы, закоммитить и запушить в GitHub (`git add . && git commit -m "update" && git push`, либо просто загрузить изменённый файл через веб-интерфейс GitHub)
2. Render автоматически подхватит изменения и передеплоит сервис — никаких дополнительных шагов, в отличие от Apps Script

## Команды и режимы

- Просто прислать ссылку, или нажать «🔍 Проверить один сайт» — бот спросит ключевые слова (можно пропустить, написав «пропустить»), затем пришлёт отчёт с кнопкой «⚖️ Сравнить с конкурентом»
- «⚖️ Сравнить два сайта» — проведёт через обе ссылки и покажет сравнение метрик

## Ограничения

- Не решает проблему SPA (сайтов, рендерящихся через JavaScript) — честно предупреждает об этом в отчёте
- Приватные/защищённые страницы не проверить — бот заходит как анонимный посетитель
